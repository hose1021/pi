# pi config (hose1021)

Конфиг агента [pi](https://github.com/earendil-works/pi-coding-agent): настройки,
расширения, скиллы, темы, правила (`AGENTS.md`), профиль (`memory.md`).
Автоматически синхронизируется между машинами через git.

## Установка на новую машину

Требуется: установленный pi и GitHub-доступ (см. ниже).

```bash
# если ~/.pi/agent уже создан pi со стандартным конфигом — убрать его
rm -rf ~/.pi/agent
# склонировать конфиг
git clone https://github.com/hose1021/pi ~/.pi/agent
# перезапустить pi — расширения и настройки подхватятся
```

На машине, где конфиг уже стоит (например, после установки на второй системе):

```bash
git -C ~/.pi/agent pull --rebase
```

### GitHub-доступ

Чтение/запись репозитория:

```bash
gh auth login        # HTTPS + токен (рекомендуется)
# или SSH:
git -C ~/.pi/agent remote set-url origin git@github.com:hose1021/pi.git
```

## Автосинк

Расширение `extensions/sync.ts`:

- **при старте сессии** — `pull --rebase` (локальные незакоммиченные правки сначала
  прячутся в stash, потом возвращаются);
- **при завершении сессии** — commit + `pull --rebase` + `push`.

Сбои (нет сети, конфликт) молча игнорируются — сессия pi никогда не ломается,
расхождения разруливаются при следующем старте.

## Что синхронизируется

```
AGENTS.md              правила (rtk, команды)
settings.json          пакеты, тема, модель, провайдер
memory.md              профиль пользователя
extensions/            расширения (исходники, без node_modules)
skills/                скиллы
themes/                темы
fff/                   pi-fff (источники, не данные)
git/                   установленные git-пакеты
```

## Что НЕ синхронизируется (машино-локальное)

`.gitignore` исключает: `auth.json`, `models-store.json`, `trust.json`,
`sessions/`, `npm/`, `bin/`, `node_modules/`, `*.log`, `ayu/` (чекпоинты
pi-rewind), `pi-fff/` (LMDB-базы frecency/history), `logs/`.

⚠️ Не добавляйте секреты и личные данные в репозиторий — он может быть публичным.

## Заметки

- Не редактируйте `meta/` или `raw/` вручную (если заведён LLM Wiki) — ими
  владеет расширение.
- После добавления/удаления пакетов в `settings.json` — закоммитьте: автосинк
  закоммитит при завершении сессии, но явный коммит надёжнее.
- Правила `.gitignore` не пишите с хвостовыми комментариями
  (`pi-fff/ # comment` не матчится на git 2.39) — только чистый паттерн.
